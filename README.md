# Ordering Business App

Run Business App locally for your Ordering project and see your first edit on screen.

## 1. Paste this into your coding agent

```text
Open https://github.com/Ordering-co/ordering-app-business.git and read docs/onboarding.md. Help me run Business App locally for my Ordering project, confirm the selected project on screen, and make one visible change.
```

## 2. Confirm your project

Tell the agent which Ordering project to use, or let it identify the project through your existing Ordering connection. App sign-in, when needed, is separate.

## 3. Open your app

Check that the project name on screen matches your choice. Ask the agent for one small visible edit and confirm the change appears.

The local preview opens Home and Login without push setup. Production setup is covered in the runbook.

For iOS, use macOS and Xcode; for Android, use Android Studio, the Android SDK and JDK.
